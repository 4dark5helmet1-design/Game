# ЗАБОЙ — сборка отдельного приложения

Здесь лежит обёртка на Electron: то же самое `game.html`, но в собственном
окне. В нём **Esc принадлежит игре целиком** — браузер не может отобрать
полноэкранный режим, потому что браузера нет. Выход из полного экрана — F11.

## Собрать .exe для Windows

На Windows, где стоит Node 18+:

    cd desktop
    npm install
    npm run dist

Готовое приложение появится в `desktop/out/win-unpacked/` — там `ЗАБОЙ.exe`.
Папку можно перенести куда угодно целиком; запускается двойным щелчком.

Сборка тянет Electron (~150 МБ), поэтому первая занимает пару минут.
Готовая папка весит около 360 МБ: это цена того, что внутри лежит целый
браузерный движок и интернет приложению не нужен.

**На Linux `npm run dist` для Windows не доработает до конца:** упаковка
проходит, а на подписи исполняемого файла требуется Wine. Само приложение
в `out/win-unpacked/` при этом уже собрано и работает.

## Просто запустить, не собирая

    cd desktop
    npm install
    npm start

## Без Electron вообще

`docs/zaboy.html` — та же игра одним файлом. Открывается двойным щелчком в
браузере, ничего ставить не надо. Отличие одно: Esc там выходит из
полноэкранного режима браузера, отобрать его насовсем нельзя.
